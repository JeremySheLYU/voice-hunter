# 第二階段自動分軌候選

候選模型接收 48 kHz 的雙聲道音訊，從吉他、鋼琴、語音、列車和風中找出指定類別，並輸出和原音等長的立體聲音軌。當兩個聲像不夠穩定、方向無法分開，或該類別的證據不足時，系統會拒絕輸出。使用說明與命令列參數可用 `python -m round3b.extract --help` 查看。需要 macOS 的 SoundAnalysis、FFmpeg、NumPy、ONNX Runtime 與專案的 YAMNet、AST 預訓練權重。個人的 iPhone 錄音沒有用於這次訓練或驗證。

## 修改內容

- 以預定雜湊順序從既有訓練集每類選 45 個錄音，把 AST 有監督遷移訓練從 75 個擴至 225 個。Apple 和 YAMNet 的分類頭使用 625 個訓練來源。
- 以錄音上傳者為單位做五折訓練，讓每個樣本先由沒看過該上傳者的分類頭打分，再用這批分數學習類別權重。結合 AST、Apple SoundAnalysis、YAMNet 的通用分類線索與各自重新訓練的分類分數。同一個原始錄音沒有跨越這五折產生自己的基礎預測。
- 根據訓練預測做出模擬正例與缺席請求，估計個別類別門檻。開發集比較後選用共同門檻 0.24 和混合係數 0.5，分類器仍保留五類各自的權重。
- 先從分頻、分時段的聲道協方差檢查方向是否穩定。估計兩條聲源軌時依序嘗試方向聚類、時域協方差與時頻協方差聯合對角化。三種方式都以觀測到的雙聲道訊號工作，沒有讀取乾淨真值或聲源位置標註。

## 開發集與獨立評估

調校用原始的 55 組錄音配對，持續出聲和間歇出聲共用這些配對。每種情形有 55 次目標存在及 55 次目標缺席。分軌改善以對照輸入之重疊時間區段 SI-SDR 提高至少 3 dB 衡量。雖然原始音檔為實錄，設定左右聲像的步驟為可控混音。來源標籤為 FSD50K 等公開資料的既有標註；指定類別缺席是依標註推定。

| 開發驗證 | Accuracy | F1 | 有用分軌 | 目標缺席仍交軌 |
|---|---:|---:|---:|---:|
| 持續出聲 | 88.2% | 0.883 | 49/55 | 7/55 |
| 間歇出聲 | 85.5% | 0.857 | 48/55 | 9/55 |

這些數字屬於調校集，不能用來判斷 90% 的最終驗收是否通過。正式評估時，獨立評測人員使用凍結的 `freeze.json` 和沒有參與選擇的新資料。同一份已公開成績的舊考卷只當回歸測試。YAMNet 與 AST 的原始預訓練來自外部，無法完全排除外部預訓練來源重疊。

## 重跑訓練與確認

由專案根目錄使用含 NumPy 和 ONNX Runtime 的 Python 環境。先備妥 `round3/data/train.json`、`round2/semantic/cohort.json` 列出的音檔及上游模型檔。在另外解壓的專案副本依序執行下列指令可重建這個模型。訓練腳本會寫入相同位置的權重。

~~~sh
python round3b/model/encode_train.py
python round3b/model/encode_prior.py
python round3b/model/dev_features.py
python round3b/model/train.py
python round3b/model/check.py
~~~

`check.py` 會核對開發集全部 220 個請求的類別表現，並以完整波形重跑涵蓋一般路徑與後備路徑的八個片段。`replay.json` 收錄逐筆結果與執行時間。`training_sources.json` 紀錄 225 個 AST 調校樣本，`freeze.json` 保存檔案校驗值與訓練折數。
