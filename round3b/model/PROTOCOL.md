# Phase 2 training and confirmation protocol
Features and tuning use only the first phase's permitted 625 training IDs and original validation split. No prior or newly acquired final scores, labels or waveforms are used for selecting this model. Expand AST transfer to 45 supervised recordings per class in the pre-existing deterministic train-source order (225 in total). Refit upstream AST, Apple and YAMNet heads across uploader-disjoint training folds to obtain out-of-fold category evidence. Learn a small shared-plus-class-specific multinomial evidence combiner on these out-of-fold predictions. Include every other class as a negative with the existing weak-label caveat. Class thresholds are estimated using balanced positive and absent requests from deterministic pairs of out-of-fold train-source predictions. Use the previous controlled validation split to select only a global operating point, modest shrinkage of class-specific thresholds and evidence blend, maximizing the minimum of accuracy and positive-class F1 in both conditions, then useful fraction. Source selection, output evaluation and rejection criteria remain frozen before the new confirmation is unblinded.
