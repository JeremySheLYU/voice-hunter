# v0.3b 聲學壓力測試

使用已凍結的 v0.3b 權重和 v0.3 原始測試程序，重新評估原聲像與樓梯間混響。兩組測資曾用於先前版本，本輪屬於重播診斷。每個目標條件各有一次要求存在類別和一次要求缺席類別。獨立驗證及本輪受控場景的結果另見上層 evaluation。

| 聲場 | 來源及要求 | v0.3b 準確率 | v0.3b F1 | v0.3b 有用分軌 | v0.3 融合模型有用分軌 |
|---|---|---:|---:|---:|---:|
| 保留各錄音原始左右聲道 | 19 份錄音、68 個不重複混音、76 組目標條件 | 50.0% | 0 | 0/76 | 4/76 |
| 實測樓梯間響應 | 55 組使用同一樓梯間雙耳響應的混音 | 50.0% | 0 | 0/55 | 0/55 |

v0.3b 拒絕了兩組測試的全部請求。準確率中的正確部分全是缺席類別得到拒絕，召回率為零。輸出改善門檻為相對原混音至少 +3 dB 雙聲道 SI-SDR。逐條重算顯示，全部 131 個目標條件都在聲像幾何品質檢查被擋下，尚未進入後續類別判斷。測試程序沒有執行錯誤。native.json 和 room.json 保留逐筆結果。

命令列另用已知訓練來源合成的固定聲像吉他及風聲對照驗收。程式成功輸出吉他與剩餘聲軌，保留兩個聲道與 216,000 個取樣，音軌加總的最大誤差為 2.98 × 10⁻⁸。輸入靜音時退出且未建立輸出資料夾。詳細見 cli.json。

從專案根目錄用含有模型依賴的 Python 可重跑診斷。

~~~sh
python round3b/stress/run.py room
python round3b/stress/run.py native
python round3b/stress/diagnose.py
~~~
