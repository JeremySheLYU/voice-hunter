# Second independent controlled evaluation for a challenger

Locked at the start of v0.3b before the new evaluation corpus or its model outputs were available. The v0.3 model/scorecard remain frozen.

- The quantitative target is all four point estimates >=90% (accuracy and positive-class F1 in both continuous and intermittent overlap strata). All four must be reported even when a subset passes. Report per-class F1, perceived presence versus useful waveform delivery, and source-pair/uploader-cluster uncertainty. Neither true-room nor real-phone generalization is inferred.
- The new test set must offer at least 12 eligible, newly acquired sources from 12 distinct, previously unused uploaders per class in guitar, piano, speech, train and wind. Require >=4.5s of actual audio in each file, stable authentic source identifiers, validated SHA256, and true independent uploader groups (not aliases for the same archive owner). Exclude overlap by file IDs, exact waveform digests and uploader against V0.2 and all V0.3 train, validation and held-out source files identifiable by those keys. An upstream pretrained model with undocumented clips is not certified independent from the originals; note any identifiable overlap separately.
- Use fixed source ordering by SHA256 of a constant and source ID, assign 12 distinct uploaders within each class. When counts/independence are inadequate, report lack of evaluable cohort; no substitution of training/validation data or earlier test data. Log all exclusions and never score multiple alternative cohorts or tune selection on the outcomes.
- Plan 30 disjoint source pairs, three per unordered cross-class combination. Both sources take turns as target, each with one positive and one class-absent request. Preserve positive/negative labels, original waveform length, and mixture generation common to both models. Correlated contributor clusters receive joint bootstrap weights. Report reused contributors across pairs and the cluster count. No individual request is presented with ground-truth polarity.
- Use fixed-position, amplitude-panned 4.5s stereo mixtures and SI-SDRi of returned correct targets exactly as in the original balanced corpus. Source authorization to cut/repurpose its waveform and reference track must be documented. All weak labels remain visible in limitations. One source returning a near-silent scoring window remains in the primary denominator and counts as not useful.
- Competing systems are the original v0.3 primary fusion model and one challenger frozen using existing training/validation only. For a second result, freeze the identity/model tar files and validate their hashes *before* the independent runner evaluates either one. The previously inspected v0.3 held-out scores may motivate a study question but cannot fit the model or select thresholds. Summaries include >=3dB useful/positive and the paired cluster bootstrap difference.

**Contingency fixed before outcomes.** If the original source pool falls short of 12 distinct uploaders per class, lock the failed primary feasibility verdict. A small *descriptive* run may use the largest common multiple of four eligible distinct-author recordings per class, capped at eight, if at least four eligible authors remain for every class. This does not satisfy the primary gate even if all observed values exceed .90. Any samples outside the locked recipe or coming from a newly added corpus are a separate external diagnostic.
