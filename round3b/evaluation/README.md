# 第二輪候選模型的獨立驗證

原定使用全新的五類 FSD50K 來源，每類至少 12 名以前未出現的上傳者，才允許確認新模型是否在受控混音達到 90%。凍結資料排除條件與方向配置後，核對所有剩餘候選的 WAV 檔頭。可用的獨立上傳者分別為吉他 2、鋼琴 0、人聲 118、列車 2、風聲 15。因鋼琴資料不足，連每類至少 4 人的探索性小樣本也無法組成。

`summary.json` 記錄結論，`plan.json` 綁定母體清單、排除記錄、音檔時長證據和 SHA-256。這些是採集可行性記錄，本輪沒有在新五類 FSD 資料上進行模型推論或準確率評分。

`regression/summary.json` 是新候選在 v0.3 已報告過的 60 個聲源上重跑的分數，可與舊模型在同一素材比較。它不構成第二批獨立資料驗收。

若電腦具備 macOS SoundAnalysis、NumPy、ONNX Runtime 及專案音檔，可執行 `python3 round3b/evaluation/regression.py` 重現回歸；`run.py` 保留原始新資料評分器及目標判斷規則。
