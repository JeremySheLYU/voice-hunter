# Environmental source-image calibration, preregistered product evaluation
The frozen spectral estimator remains the comparison. A proposed spatial Wiener filter uses isolated user reference spans to estimate frequency-dependent stereo covariance, and the prior spectral masks to estimate relative source energy. Apply the new branch only to two to four manual tracks with distinguishable directions and internally coherent examples; otherwise preserve the original masks. These rules are source-agnostic. The test has no visual context.

Calibrate one soft spatial likelihood temperature and one spectral-prior exponent on procedurally mixed commercial-use-permitted public recordings. Check candidate settings on disjoint validation recordings, choose the best average improvement of the weakest track per training scene from among stable candidates; validation can veto a regression but cannot select new coefficients. Restrict the candidate grid before testing to temperatures [0.025, 0.075, 0.20] in normalized squared directional misfit and spectral exponents [0.45, 1.25]. Compare candidates with the unmodified v0.1 mask method on identical mixtures. Keep the originally published nine reference waveforms from the old train/speech/wind QA reserved for the final test. Hold additional train/validation/test partitions apart by origin and by performer/recordist or collection when practicable. A new test recording must not have been used to set coefficients. Report split keys and finite set composition including repeated clips across mixtures. Raw material not required for runtime.

Generated clips have three equal-duration disjoint solo examples and a later, held-out simultaneous interval at moderately separated stereo positions. Variations cover relative gain, direct-path amplitude vs stereo delays, uneven timing and unlabelled distractors if available. Report both absolute SI-SDR and paired improvement relative to mixture for each named stereo image. Each named image must improve at least 3 dB to pass; describe the weakest track and all-scene pass counts. No post hoc permutation. Additivity ceiling 1e-6 full scale. Include original three practical speech/train/wind cases, three synthetic registers sets, neutral/duplicate or diffuse references, and existing tests. Test outcomes do not change criteria or fitted coefficients. Constant-panner/ITD mixtures are simulations made from recorded sounds, not true field measurements. Make explicit if actual captured stereo does not have separable dry truth or if a planned partition cannot be sourced.

Before calibration: every fourth scene includes an unlabelled fourth source 12 dB below the reference RMS. Prefer a true stereo source for that purpose, retaining its L/R waveform as captured; if none is available record the mono-pan fallback in the row. Select energetic disjoint sections while keeping their original chronological ordering and at least 80 ms between excerpts. Candidate selection uses training scores only; the validation veto uses the mean of the least-improved named target relative to baseline.
