# Measured horizontal interaural cues, frozen protocol

Use the full, blob-verified CIPIC Release 1.1 set (43 people, large and small pinnae on the same KEMAR). Hold both mannequin records outside training. Rank human IDs by SHA-256 of "vh2-cipic-2026/" and the three-digit ID, allocate 27/6/10 to training/validation/final test. Hold absolute directions 10°, 35° and 55° completely outside training. Use frontal horizontal responses only (elevation index 8 in CIPIC interaural-polar, 44.1 kHz). Positive azimuth is to the listener's right. Pool mirror directions at fit time for a symmetric generic renderer, using robust median band ILD and low-frequency differential-phase delay across the training people. Fix 0° to equal waveforms. Clamp above the last measured direction (80°); 80–90° is an endpoint hold, not an evaluated range.

Measure actual rendered responses against the held-out measured responses. Primary metrics are mean absolute interaural spectral level-difference error (dB; near/far ratio of band energies, geometric bands centred at 250–12000 Hz with ±1/3 octave bandwidth) and mean absolute differential phase-slope delay error (microseconds; 300–1200 Hz). Baseline is the shipped v0.1 far-ear filter sampled at the same 44.1 kHz. Report results individually per person, separately on held-out angles, and for the two KEMAR records. Exclude 0° from scoring because a symmetric generic renderer cannot represent measured centre-ear asymmetry. Advance only as optional if both errors improve on the final held-out people and both improve in the withheld-angle subset; report failures and avoid any inference about real human preference or direction judgement. Compare output on standard algorithm controls (zero azimuth, mirror inversion, impulse finiteness/length, zero residual/foreground). No test audio, azimuth labels from video, or user clip enters fitting. No iterative fitting after inspecting the test split.
