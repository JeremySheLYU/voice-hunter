# Field recordings and offline ambient-width calibration

The excerpt length and original recording ID are the unit of acquisition. Take the opening 8 seconds of each EigenScape Lite and London AmbiX member, and the opening 4 seconds of all IHTApark original FOA and corresponding binaural renders. Preserve the four ambisonic coefficient indices. Count matched FOA/ear representations only once when reporting independent source IDs. Keep collection author, license, recording name, byte interval, excerpt timing, sample rate, channels and checksums. No location or source-isolation labels are inferred from environmental class names.

IHTApark has a published binaural rendering of each scene, generated from the same field recording using an IEM / KU100 decoder. It is an authored rendering target. Design a simple correction to virtual narrow stereo ambience, using an explicit virtual crossed-cardioid pattern at ±20 degrees from the front. For SN3D coefficients [W,Y,Z,X], microphone response is 0.5(W + cos(20°) X ± sin(20°) Y). This synthetic stereo microphone model is not a measurement of an iPhone. Predeclare four frequency bands [100,400), [400,1600), [1600,6400), [6400,15000) Hz. Fit four side-channel gains from the median, across training captures, of (published binaural side-to-mid amplitude ratio minus input ratio) in dB. Clip each gain to ±12 dB. Hold the mid signal fixed. Compare to raw narrow stereo, fixed 1.35× stereo side gain, and a single broadband gain learned from training. A snapshot of weather/day has several microphone positions, so split strictly by calendar date, sorted ascending, use every fourth date (index 3,7,...) as unseen test. Remaining days train. No tuning on scores. Report equal-weighted median absolute band-ratio error over all test capture/band observations and per-capture improved counts. Require the learned curves to lower error relative to raw and the 1.35× fixed baseline. Report any tradeoff relative to a learned constant baseline. No inferences about individual object separation, localisation, distance, real ears, elevation or listening preference.
