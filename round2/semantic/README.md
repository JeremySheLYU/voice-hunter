# 免示範的指定類別分軌實驗

這個候選模型只放在研究目錄。它從左右聲道的時間／頻率資料找出兩個主要且穩定的聲像，以其混合向量估計兩條音訊，再以訓練過的聲學特徵模型分辨 guitar、piano、speech、train 或 wind。使用者只需給一個類別，推論不會讀取獨奏範例、時間、真值聲軌或方位。模型包括 606 個訓練片段特徵、帶正則的線性分類器及近鄰距離。候選得分由驗證資料的統一門檻 0.46 控制，這個分數不是已校準的機率。

## 資料及切分

凍結 285 個不同 Freesound ID。五個類別各有 35 個訓練、11 個驗證、11 個最終測試素材。錄音上傳者分組互斥，分別有 165、51、53 個不同名稱。本組沿用同專案環境聲收集使用的上傳者分組，不能把其他測試組中重複出現的素材當新的獨立來源。全部訓練／評估原材是單聲道 FSD50K 音訊，來源權利為 CC0 或 CC BY。測量資料是真實音訊，受控混音中的方向則由程式指定。弱標註的噪音／樂器音檔可能包含其他聲音，缺席標籤根據配對類別推定。授權、原作標題、作者、來源、切分與波形 SHA-256 分別在 attribution.csv、cohort.json。

FSD50K © Eduardo Fonseca、Xavier Favory、Jordi Pons、Frederic Font、Xavier Serra，資料集採 CC BY 4.0。原始各錄音的授權及作者見 attribution.csv。處理包含裁切、重新取樣、統一能量、立體聲混音與特徵擷取。 [資料來源](https://doi.org/10.5281/zenodo.4060432) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## 測試

先固定模型形式及門檻選取策略，使用驗證組選出門檻。各測試素材各用一次作為目標，匹配另一個類別的干擾音。相同配對分別製作「間歇＋後段重疊」和「全程重疊」場景，並詢問一個缺席類別。另測同位置、Aachen 真實樓梯間左右 45° 雙耳脈衝響應（控制截取 255 ms）兩組壓力條件。完全重疊部分按照輸出軌名，相對於混音計算雙聲道 SI-SDR 改善，至少 +3 dB 即列為「有用交付」。

| 測試條件 | 有用交付／55 | 輸出數／55 | 輸出後變差 | 缺席仍交軌／55 |
| --- | ---: | ---: | ---: | ---: |
| 兩個固定聲像，全程重疊 | 28 | 28 | 0 | 1 |
| 兩個固定聲像，間歇 | 28 | 29 | 1 | 3 |
| 兩個聲源同位置 | 0 | 0 | 0 | 0 |
| 實測樓梯間響應 | 0 | 3 | 3 | 1 |

兩個主要條件的有用交付皆為 50.9%，均未達預先設定的 55%。理想的兩個固定聲像使用同一個線性增益混合模型產生和反解，因此成功案例可量到很大的改善；這部分不應外推至實錄手機。實測樓梯間響應的三個有輸出案例，改善中位數為 −7.21 dB。結論是保留研究成果，產品中的既有自動模式維持其原實作。

## 同場景的原版自動方法

直接呼叫原有 Apple SoundAnalysis＋NMF 分離介面，對同一批 110 個場景各請求存在與缺席的類別，共 220 次。以「有用交付／55 個應交付案例」計，全程重疊原版 15/55，候選 28/55；間歇原版 13/55，候選 28/55。全程重疊的缺席誤交為原版 8/55、候選 1/55；間歇為原版 7/55、候選 3/55。使用相同雙聲道參考與重疊時間，在這兩個理想化固定聲像條件的交付有所改善，但候選未達絕對放行門檻。原版實測數字見 apple_results.json。另試的併批快取方法在波形等價檢查失敗，正式基準只採完整逐次呼叫的結果；不要將本次與前一輪 8/30 的不同測資直接相減。

同位置和樓梯間壓力測試的候選結果已列入上表。類別缺席請求仍取自相同五類的組合，並未驗證任意未知聲音的開放類別辨識。測試語音、樂器與環境聲均取自公開錄音，相同來源在重複條件間的關聯需要保留在解讀中。

## 重現

從專案根目錄使用 Python、NumPy、FFmpeg。蘋果自動模式另需 macOS SoundAnalysis 及編譯工具。可先比對 cohort.json 的來源 SHA-256。僅執行評估可用 --evaluate-only。依 evaluate.py 目前的基準命令，Apple 的進度檔會逐次寫入 `apple_{stratum}_checkpoint.jsonl`。預設每次重新評估；中斷後可加 --resume-apple 繼續。實測樓梯間使用 round2_data/spatial/aachen/ 下相應兩條響應。

~~~sh
python3 round2/semantic/evaluate.py
python3 round2/semantic/evaluate.py --apple
~~~
