# No-reference semantic extraction, prospective gates

Use the frozen FSD50K/Freesound cohort.json and its train, validation and test partitions grouped by source uploader. Verify all hashes; require disjoint uploaders and source IDs across splits. No private, held-out or NC recordings enter fitting. Classes: guitar, piano, speech, train and wind. Each source has one weak clip label; a label does not guarantee absence of all other sounds. Fit compact regularized class models or spectral feature dictionaries on training-only dry mono excerpts. Deployment receives only the requested class and a two-channel waveform, never a reference time span, ground truth position, class list of the distractors or clean waveform. Infer two dominant stationary stereo level directions; demix those apparent positions and use the trained model to attach a semantic name. Reject co-directional, diffuse, or unreliable estimates when evidence is weak.

Build at least one test scene per eligible held-out target file with a different-class distractor and at least one absent-class request; retain all planned rows, rejections, errors and null targets. Two strata use (i) a target intermittent over the bed then both fully overlapping or (ii) a continuously overlaid pair. Choose varying fixed panning and alternating target side in controlled mixtures, nominal equal energy, with source interval and normalized energy preserved. Do not optimize across test results. On the development validation set only choose a confidence gate to deliver the most positives under <=15% false accepts (or report no viable gate). Frozen success policy on final controlled test: each returned target should improve stereo SI-SDR by >=3 dB over input on evaluated overlap; report all-intended useful fraction, coverage, wrong-return fraction and negative false accepts. Advance as an optional, explicitly two-position candidate only if useful positives >=55% in both strata, false accepts <=20% overall, and more useful positive deliveries than the Apple v0.1 automatic mode on the same scenes, where available. No deployment if candidate misses gates. Include positive, negative and counterexample data; COLOCATED and actual recorded binaural-room stress separately reported, no product claims from those trials.
