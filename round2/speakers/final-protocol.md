# Independent release holdout after refinement
The Mini dev and historical QA results informed a second iteration. Replaced local binary decisions with two-state dynamic programming and added a preflight check requiring a minimum 8 dB intended/other output energy ratio in both enrolled solos. This confidence guard may refuse true sources in reflective rooms; refusals remain in the denominator. Do not count refusals as successful separation.

Before evaluating any official test-clean source, freeze source and model fingerprints in final-lock.json. Run the same dry/stairway scenarios, paired fixed vs exchanged, using all speakers in official OpenSLR 12 test-clean. Assert no speaker appears in either Mini subset. Pairs and index rules are deterministic, two enrollment/target utterance combinations each, shared across dry/room and baseline/candidate, with no tuning on this final set. A crossing passes only if both speakers' waveform SNR improves at least 3 dB relative to the original mixture after the exchange. Also report harmful returns and refusals separately. A useful release candidate must improve crossing pass count over v0.1 without losing successful fixed cases in the simple room. Recheck all reported numbers when changing runtime source. Do not optimize against the final set later.
