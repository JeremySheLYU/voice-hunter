# Stereo cancellation protection for the measured headphone profile

Fit a scalar lower bound for foreground midpoint retention using distinct artist-grouped FMA-small excerpts with verified CC BY or CC0. Freeze the split by artist ID before decoding. Real untouched stereo is the fidelity control. For labelled failures derive a near-coincident foreground from that same real waveform, vary its harmless stereo component, and reverse one channel for a central 1.3 s. The true channel-change interval is known; this stress probe does not assert a wiring fault in the original.

On 40 ms Hann-weightless energy windows with 20 ms hop measure p = power((L+R)/2) / mean(power(L),power(R)). Ignore intervals below -70 dBFS. Candidate retention thresholds are 0.03, 0.06, 0.10, 0.16, 0.24. Score pure negatives (untouched stereo marked for fallback) and positives (known inverted active frames detected) per recording. Choose the threshold with maximum recording-averaged positive recall subject to <=1% average untouched frames flagged on training data; break ties toward the lower threshold. Use validation only as a deployment gate, never refit on test. Report coverage, untreated baseline retention and mapped fallback energy on artist-disjoint test split. If validation's false fallback exceeds 2% or positive recall <80%, keep the feature out of the runtime.

The fallback crossfades locally from a virtual object to its original stereo foreground where mono-fold cancellation occurs. It preserves ear signal energy and avoids fabricating the requested position in that interval. Relative left/right polarity is ambiguous when a true stereo source has spatially opposed components; no direction or perceptual result is inferred from a flagged time. Routine stereo/analytic rendering remain available. The baseline and enabled profile use identical gain/width. Evaluate controlled failure intervals at centre azimuth so both input midpoint and fallback energies have a directly comparable physical reference.
