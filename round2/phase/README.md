# 耳機模式的局部反相保護

前版把兩個聲道取平均送入耳機點聲源渲染。當某個片段左右極性相反，平均值接近零，即使整條軌通過全局檢查，該片段仍然可能消失。新實測耳機模式每 20 毫秒評估一次 40 毫秒窗，依單聲道折疊後能量相對兩耳能量的比例，平滑退回該片段原有的立體聲。觸發區間的方位遵從原始聲像。幾何耳機模式提供原有比較。

校準使用 FMA 實際錄音，注入時間已知的單聲道極性翻轉。訓練 140 位、驗證 23 位、最終測試 30 位音樂作者，每位一首。五個候選能量比例中選定 0.24。最終測試中，已注入錯相且有聲的區間檢出平均 99.94%，原始未改錄音中平均 0.35% 的有效檢查窗會觸發。後者是對未改素材的反應頻率，天然反相內容未有人手標註。受控錯相區間以總耳訊號能量為參考，絕對誤差由 16.30 dB 降至 0.0054 dB。這項量測使用正前方渲染，沒有受試者作方位或自然度評分。實際生產入口另以人工建立的半秒以上抵銷區間，檢查保護確實生效。
