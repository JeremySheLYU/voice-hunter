# v0.2 獨立整合測試

工作目錄為完整專案根目錄，原始 v0.1 壓縮檔放在 outputs/VoiceHunter_v0.1.zip。用 `python3 round2/independent/run.py` 重跑 CLI、HTTP、訓練／評分來源分離、相位與舊版相容性；用 `python3 round2/independent/native_pair.py` 重跑兩份真正雙聲道錄音的額外比較。兩個來源的下載與雜湊見 round2/envdata，開始前可執行 restore.py --all-versions。訓練來源稽核另需還原 fielddata 中使用過的 IHTA 環境底聲，或在本次取得資料的機器上執行。固定輸入、事前準則和逐項結果都在本目錄。

實際 CLI 和本機 HTTP API 均成功跑通雙參考分軌、移動雙人及量測耳機設定。+90° 與 0° 的輸出混音有差別，而可編輯的來源分軌完全相同。特意設置局部左右反相的測試中，該段在 +90° 耳機渲染後保留原有 RMS 的 100%。從沒進入擬合候選集的一段真實雙聲道「Indoor_Wind.wav」（iimck，CC BY 3.0）在 CLI 和 HTTP 下匯出的聲軌與混音逐位元相同。這個例子沒有現場各物件的獨立錄音或角度，只用來驗證實際檔案流程。

另一個額外對照取兩份新的雙聲道來源，保留原來的左右聲道，先用各自的獨立片段校準，再同時播放較後三秒。相對各自真值的 SI-SDR 改善為火車 +4.09 dB、風 +6.20 dB。v0.1 及 v0.2 在這一組數值相同。兩個聲軌都過 +3 dB，本組沒有觀察到新版額外改善。

從實際試驗紀錄逐一稽核來源，主訓練與驗證、主訓練與測試、驗證與測試三對組別的錄音 ID 與具名 Freesound 投稿者交集都是 0。場景使用的附加 FOA 底聲以錄音 ID 及雜湊核對。收錄來源總數、凍結候選清單和實際配方使用的次數分開記錄。分軌、瀏覽器主觀聽感與聲音原始物件的準確度分別需要各自適當的真值。

預設以擬合與測試時的來源檔雜湊和原始收據交叉檢查。需要再次逐一讀取所有原始大檔核對 SHA-256 時，可執行 `python3 round2/independent/run.py --verify-raw`。本次 368 個環境音檔的兩種表示都另做了完整位元核對。
