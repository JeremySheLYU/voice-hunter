# Acoustic transfer stress test for the five-class requested-source task

Frozen before running any Round 3 candidate. All comparisons use the same requests, require no timing/example information, preserve existing source waveforms, and score requested-class presence and the returned audio separately.

1. **Measured stairway.** Replay the 55 original Round 2 held-out source pairs through the same measured left/right Aachen stairway responses (255 ms; source directions ±45°). One 4.5 second scene is queried for one present and one absent class. Prior Round 2 scores on this known failure were public. New model development receives no held-out audio or per-scene signals.
2. **Native stereo without panning.** Use all 16 eligible recordings from Round 2's original L/R inventory (the seventeenth was already excluded as near dual-mono). Each recording serves as target four times, once with each other class. For each target–class pairing choose a held-out recording of the other class from a different uploader deterministically, using the least-used eligible distractor then a fixed hash tie-breaker. For the absent request, pick an eligible absent class with the lowest previous count, with a fixed hash tie-breaker. Take the centered 4.5 seconds of each capture, decode to 48 kHz stereo, apply one scalar per source to obtain equal stereo RMS, add samplewise, and peak scale the entire scene if necessary. This models coincident recordings, not a single live scene. Native negative labels are inferred from each clip's catalog target, not manually established absence. No probe, mid/side manipulation, or synthetic panning is added.
3. Both conditions have one positive and one negative requested class per scene. Score presence by whether the product returns a finite, time-aligned, two-channel stem. Report TP/FP/TN/FN, Accuracy, positive-class F1, and false positives. For each positive, compare returned output on the shared time span [0.15, 4.35) seconds with its true stereo source using the same stereo SI-SDR and baseline mixture as Round 2. Separately count useful positives (improvement ≥3 dB), harmful outputs (improvement <0 dB), and useful fraction over all intended positive requests. A refusal or pipeline error cannot count as a useful response. Unexpected processing errors make a benchmark incomplete and receive an explicit status, not a correct-rejection credit.
4. Include by-request-class counts, useful rates, and failure details. Counts use non-independent conditions: the native stratum has only 16 unique source recordings, including repeated use of each, and the measured room has one actual room. This is a transfer stress diagnostic and should not be pooled into the primary 90% claim. Report the old research method on both conditions. Where the pre-existing Apple production recognizer is available, measure it separately.
5. Do not change a model, thresholds, source order, or eligibility criteria because of these results. Record the SHA-256 of the manifest, stress script and the frozen candidate model files alongside results. The standard test runner interface is a module exposing load_model() and predict_scene(audio,sr,model), returning a map from all five class names to a float stereo stem or None. Report source/protocol overlap with earlier rounds. Source licenses/hashes from the existing frozen data manifests apply.
