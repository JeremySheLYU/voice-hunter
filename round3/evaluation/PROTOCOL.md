# Voice Hunter round 3 frozen evaluation protocol

This file was created before new candidate results or fresh labels/audio were scored. It evaluates extraction without user-provided examples for guitar, piano, speech, train and wind. A request declares presence if the system returns a finite stereo track matching the mixture length. A deliberate refusal declares absence. Runtime failures are errors that must be fixed before releasing the result. A correct positive detection may still contain the wrong or unusable waveform.

**Primary model selection and claim.** Select one model before unblinding, using validation only. Rank candidate models by their minimum of accuracy and positive-class F1 across the two validation strata, then by the smaller fraction of useful positive deliveries across strata; break remaining ties by lighter runtime (local NumPy, OS-provided model, external pretrained model, with actual tie noted). Freeze the selected code, trained weights and thresholds. Evaluate other frozen candidates on the same test only as exploratory. No threshold adjustment, data exclusion on perceived difficulty, or reselection from test scores. Historical scores are regression evidence only. Passing the requested 90% target requires point estimates of both accuracy and binary positive-class F1 >=0.90 in each of the two fresh fixed-position conditions. Report uncertainty, denominators and extraction separately. This point-estimate target is not evidence that a population lower bound exceeds 0.90, that open-set detection works, or that real phone recordings reach the same accuracy.

**Sources and truth.** Use the fresh frozen corpus from round3/data; source uploaders, IDs and audio digests must be disjoint from earlier semantic sets and additional training data. Weak labels and absence determined by the documented source annotations, not manual confirmation of every acoustic event. Generic pretrained networks' exact upstream overlap may be unknown and must not be represented as guaranteed. Include all available eligible clips in the controlled primary set up to the preregistered target of 20 per class. If fewer are available, take the largest common multiple of 4 per class, report exclusions by class and preserve their identities. Integer hash ordering, independent of audio, determines any tie. New scenes exhaust all ten class pairings equally. Each file belongs to a single unordered pair; both members take one target turn in each condition. Use both labels as targets and draw a deterministic, absent label, balanced over class counts when possible, for every turn. The source pair and contributor clusters, and not individual requests from each pair, are resampling units.

**Acoustic conditions.** Historical regression uses the original scripts' 4.5-s equal-level source excerpts with fixed left/right positions and the original per-request labels. The fresh test uses the same audio cropping, RMS normalization, pan families and stereo SI-SDR implementation. For each source pair, target turns may use different pan pairs and panning side balanced by global scene index, independent of class. Sources are authentic recordings placed at synthetic stationary positions; native stereo is downmixed to mono for this test. Persistent means both sound throughout. In intermittent clips the target is silent from 1.10 through 2.15s and the other source starts at 1.10s. Score shared activity at 0.15–4.35s and 2.45–4.35s respectively. Preserve and score all planned cases, including withheld outputs. Total sound absent in a reference scoring window is reported as undefined rather than hiding the input.

**Metrics.** The two conditions remain separate. Report TP/FP/TN/FN, accuracy, positive-class F1, precision and recall, overlapping-window SI-SDR improvement >=3 dB / all present, and returned tracks whose quality is worse than input. Compute class-level metrics by requested class, and report unweighted macro F1. For fresh data give deterministic percentile intervals (2,000 cluster draws) for aggregate accuracy, F1 and useful delivery, resampling disjoint source pairs; merge pairs that share an uploader. Intervals condition on the source corpus and mixture recipe. Counts across repeated conditions must not be summed as independent recordings. Report same-position/room/natural-stereo stress separately wherever available. A 90% extraction claim needs useful delivery >=90% in each claimed condition.
