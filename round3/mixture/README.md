# 五類聲音的立體聲分軌候選

主候選稱為 `mixture`。它由相同錄音的短時、分頻左右聲道協方差估計兩個聲源方向，接著用兩條分離聲軌與整段混音辨認指定類別。五類涵蓋吉他、鋼琴、人聲、列車和風。估計兩個可分的固定左右聲像需要明顯的空間差異；假如局部協方差不符合估計的方向，或兩聲道幾乎相同，系統會拒絕交軌。

## 已凍結的測試方式

`round3.mixture.gateway.Predictor().prepare(audio, 48000).predict(label)` 回傳與輸入同長的雙聲道陣列，或回傳 None。共用的 `round3.mixture.model.predict_scene(audio, 48000)` 可一次取得五類輸出。`freeze.json` 記錄程式、決策係數、模型及訓練清單的 SHA-256。獨立最終測試由 `round3/evaluation` 與 `round3/stress` 完成。

混音類別模型使用 175 個既有訓練音檔和 450 個新增訓練音檔。舊訓練資料按上傳者與調校資料隔離。使用所有 625 個訓練音檔製作 1,600 個 1–3 類混音，其中部分加入合成反射。從 YAMNet 抽取特徵並擬合帶正則的核迴歸模型。用相同 625 個錄音擬合的單聲軌模型來自 `round3/transfer`，兩個模型共用凍結的 YAMNet。五類音檔來源、授權、上傳者及指紋見 `round2/semantic/cohort.json` 與 `round3/data/train.json`；YAMNet 的獨立預訓練來源見 `round3/transfer`。訓練及驗證使用素材的弱標籤。追加素材沒有消除原始錄音內其他未標事件可能帶來的影響。

## 調校與驗證

在開發集上，先測量兩個聲道是否支持同一個瞬時混合矩陣，再以固定係數網格校準單軌及整段混音的辨識結果。資料皆為真正來源錄音，但左右聲像或房間傳輸經程式設定。正例與反例各 55 次。兩個驗證條件採用同一批錄音及混音配對。

| 驗證條件 | 準確率 | 二元 F1 | 有用交軌 | 輸出變差 |
|---|---:|---:|---:|---:|
| 同時持續出聲、固定聲像 | 80.0% | 0.807 | 46/55 | 0 |
| 間歇出聲、固定聲像 | 80.9% | 0.817 | 46/55 | 1 |
| 實測樓梯間響應 | 50.0% | 0 | 0/55 | 0 |
| 相同位置／雙單聲道 | 50.0% | 0 | 0/55 | 0 |

有用交軌要求真正對應該類別的來源 SI-SDR 相對混音至少提高 3 dB。原始類別檢測命中仍可能交出更差的聲軌。開發集上，如果一個知道真實答案的評分程式每次挑兩軌中較好的一軌，兩種固定聲像都可達 55/55；這一項單純測量分軌器的上限。樓梯間的兩軌無法達到這個標準，所以上表主候選不交軌。 `jointdiag_validation.json`、`gateway_params.json` 和 `replay.json` 分別收錄波形分離、驗證調校及從頭推論的驗證數字。

## 另做的混響與單聲道實驗

試過以頻率相依的兩聲道獨立向量分析來估計混響聲源。在同一批樓梯間驗證混音，即便知道正確答案，兩條輸出中有一條達到 +3 dB 的案例也只有 2/55。另用 175 個訓練音檔學習類別頻譜字典，以及 625 個訓練音檔學習整段混音辨識，再以短時空間協方差調整目標遮罩。這個頻譜方案在樓梯間交出 7/55 條有用音軌，另有 28 條比原混音差；同位置時 5/55 有用、27 條較差。保留為獨立研究程式 `mix_model.py`。主候選不啟用這個輸出。 `mix_validation.json` 記錄逐例結果，`validation.json` 為基礎字典及盲分離的早期對照。獨立向量分析探索參考 Scheibler 與 Ono 的 iterative source steering 方法 (ICASSP 2020)。

## 重現

使用 Python、NumPy、FFmpeg 和 `round3/transfer/requirements.txt` 所列 ONNX Runtime。驗證推論直接執行 `python round3/mixture/verify_gateway.py`。從頭重建實驗請在另一份專案副本依序執行 `train.py`（基礎字典）、`train_mix.py`（混音頭及遮罩驗證）、`diag_check.py`（候選兩條軌各自的單軌特徵與驗證）、`calibrate_gateway.py`（選擇混合比重及門檻）、`verify_gateway.py`（重新從波形獨立計算）。先準備原始檔案與 `round3/transfer` 已訓練模型。訓練腳本會覆寫同路徑的模型。歷史驗證中先測過使用 175 個檔案及 840 個合成混音的混音頭，最後版的上述數字使用 625 個檔案及 1,600 個混音。
