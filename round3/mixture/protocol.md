# Five-class spectral separation in less predictable stereo
Only round2/semantic/cohort.json train and validation audio is available to method selection. No test audio or scores will be used in training. The base candidate tests two approaches: (1) use frequency-dependent blind stereo separation then assign semantic class from each recovered signal; (2) when spatial cues are absent or unstable, estimate class images with nonnegative spectral dictionaries learned from independent known-class clips. An estimate may be refused. Each method outputs the original two-channel length at 48 kHz. A target is useful when SI-SDR exceeds the original mixture's SI-SDR by 3 dB. Evaluate balanced present/absent requests, accuracy, F1, and useful positives separately. Tune confidence on validation only and disclose performance if the 90% target is missed. Historical and new test results are owned by independent evaluators.
