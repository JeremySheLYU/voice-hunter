# 主模型的實作與重訓

先把雙聲道估計成兩個固定聲像。聲像直方圖沒有兩個可信峰值時，改以多個短時間窗的協方差估計兩個混合方向。若方向過近或無法找到穩定分解，模型會拒絕輸出。這個檢查無法攔住所有反射聲、環境聲或錯誤類別。

每個聲像同時計算 Apple 聲音事件特徵和 YAMNet 表徵，使用各自在 625 個來源上訓練的分類頭評分。驗證集選出的融合比例是 Apple 0.8、YAMNet 0.2，五類共用 0.15 的輸出門檻。先對同類音軌打分，再決定是否交付。門檻和融合比例都沒有從最終評分選出。

在安裝 FFmpeg、macOS SoundAnalysis、命令列開發工具與 requirements-research.txt 之後，從專案根目錄執行 apple_features 與 transfer 的訓練腳本，產生最終分類頭與驗證特徵快取，再執行 `python3 -m round3.fusion.train`。工作台與命令列只載入部署用權重，不使用訓練快取。逐筆驗證與最終測試分開保存。

針對不在五類內的錄音，另取 30 段全新狗吠、貓叫、鐘聲、時鐘和滴水，沒有進入任何分類頭的訓練。弱標籤推定沒有五類目標。15 組混音各問五類，75 次請求仍誤交軌 26 次。這個實驗不支援任意類別的自動分軌。
